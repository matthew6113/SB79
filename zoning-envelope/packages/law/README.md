# @zoning-envelope/law

The single source of truth for every legal number in this monorepo.

Phase 1 adds `sb79.json` (SB 79, Gov. Code §§ 65912.155–65912.162), its zod
schema, and `evaluateSite`. Until then this package is intentionally empty:
no height, density, FAR, percentage, threshold, or date may be written
anywhere else in the code or prose, and none may be added here without its
Government Code citation.
